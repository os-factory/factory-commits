# Security

Please report vulnerabilities in the specification or in the reference implementations privately through [GitHub security advisories](https://github.com/os-factory/factory-commits/security/advisories/new), not in public issues. We aim to acknowledge reports within 3 business days.

Factory Commits proofs are only as trustworthy as the signer you trust: an unsigned (L1) proof is a record, not evidence against a malicious author. A signed `self-reported` proof (L2) shows who vouches for it, not that the stages ran, because a coding agent running as the developer can produce one. See SPEC.md §2, §8 and §11.
